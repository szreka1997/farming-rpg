# Farming RPG

A small **2D farming RPG** hobby project developed with **Unity and C#**.

The project was originally created while completing a Unity 2D Game Development course on Udemy. After completing the course, I continued developing the project independently, expanding its functionality and implementing additional gameplay systems.

## About the Project

The game combines farming, exploration, and RPG-style mechanics in a 2D environment.

Rather than stopping at the course material, I used the project as an opportunity to experiment with game development and extend the original implementation with my own features.

One of the main additions I implemented after completing the course was the **complete in-game shop system**.

## Features

* 🌱 2D farming gameplay
* 🛒 Custom-built shop system
* 🎮 RPG-style gameplay mechanics
* 🗺️ Multiple game areas and scene transitions
* 💰 In-game economy and purchasing
* 🎨 Custom visual assets
* 🧩 Gameplay systems implemented in C#

## Tech Stack

* **Unity**
* **C#**
